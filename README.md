# BJ Beyond Pro

Production site for [bjbeyond.pro](https://bjbeyond.pro).

This repository now contains a deploy-ready Next.js site with:

- English-first homepage
- Premium editorial Tech section
- Rebuilt Ultrahuman Ring Pro buyer-notes page
- Affiliate disclosure
- SEO metadata, sitemap and robots
- No binary dependency required for the first deploy

## Deploy

Use Vercel or any Next.js-compatible host.

```bash
npm install
npm run build
npm start
```

## Priority page

`/tech/ultrahuman-ring-pro`

The Ultrahuman page is intentionally written as buyer notes, not as a fake hands-on review. It avoids unverified medical/performance claims and clearly marks price, availability and discount-code checks as things to verify at checkout.
